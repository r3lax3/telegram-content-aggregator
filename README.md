# Telegram Content Aggregator

Микросервисная система для автоматического сбора, хранения и дистрибуции контента из Telegram-каналов в свои каналы.

## Что делает

Scrapper-сервис — это **stateless real-time API**: на каждый запрос он вживую скачивает публичное превью донорского канала с `t.me/s/{channel}`, парсит посты (текст, изображения, видео, альбомы) и сразу отдаёт их. Своей базы у скраппера нет. Bot-сервис по расписанию запрашивает свежий контент, фильтрует рекламу, чистит внешние ссылки и публикует в целевые каналы.

Поскольку медиа берётся в момент публикации, ссылки на Telegram CDN не успевают протухнуть (раньше при хранении в БД они становились недействительны через пару часов).

## Стек

- **Python 3.9+** / asyncio
- **FastAPI** — real-time REST API скраппера
- **Aiogram 3** — Telegram-бот
- **aiohttp + BeautifulSoup** — парсинг публичных превью каналов с `t.me/s/{channel}`
- **SQLAlchemy 2 + asyncpg** — ORM и асинхронная работа с PostgreSQL (только в боте)
- **Dishka** — dependency injection
- **APScheduler** — планировщик задач (публикация по расписанию)
- **Docker Compose** — оркестрация всех сервисов

## Архитектура

```
                  запрос в реальном времени
[Bot] ───────────────────────────────────────▶ [Scrapper] ──▶ t.me/s/{channel}
  │  ▲                                            (stateless)
  │  └── PostgreSQL (дедуп + прогресс циклов)
  ▼
Целевые каналы
```

- **Скраппер** не хранит состояние: каждый `GET /posts?channel=...` отдаёт свежие посты с актуальными ссылками на медиа. Есть ретраи на таймаутах.
- **Бот** хранит в своей БД, какие донорские посты уже использованы/помечены рекламой (дедуп), и **прогресс цикла рассылки** — если бот перезапустился в середине рассылки, при старте он продолжает с того же места, а не начинает заново.
- Отправка медиа умеет одиночные фото/видео и **альбомы** (`send_media_group`), с ретраями на временных ошибках.

## Запуск

```bash
cp scrapper.env.example scrapper.env  # заполнить конфиг скраппера
cp bot.env.example bot.env            # заполнить конфиг бота
docker compose up -d
```
